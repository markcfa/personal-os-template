# Personal OS bootstrap for a local agent

Read `~/.agents/AGENTS.md` as the user's global instructions, then read `MAP.md` in the same repo. Follow any relevant `skills/*/SKILL.md` before acting. Treat the repo as shared working memory and navigation, not as permission to copy sensitive material into Git.

When the task produces a durable cross-agent decision or reusable lesson, update the right file under `knowledge/`. After completing a repository change, run `scripts/sync-personal-os.sh --force` and report its result faithfully.

# Weekly review

## 1. Systems health first

If anything automated feeds your week (syncs, dashboards, scheduled jobs): verify it actually ran before trusting its output. Silent failure compounds — check freshness stamps, not vibes.

## 2. Backlog sweep

Open the task pool. Everything untouched for 60+ days gets one of three verdicts: file it, do it this week, or kill it.

## 3. People pass

Who's owed a reply, a thank-you, a check-in? Pick a small number and put them in the week. Apply `people/AGENTS.md` rules.

## 4. Plan the week

- Calendar scan: clashes, travel, prep needed.
- <Exercise / practice / creative targets — whatever you count weekly.>
- Top priorities against `goals/north-star.md` — if the week's plan doesn't touch the 90-day list, say so out loud.

## 5. Close

Log any decisions to `knowledge/decisions.md`. Update `MAP.md` if anything structural changed. Commit.
